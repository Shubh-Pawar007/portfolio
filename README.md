# Shubham Pawar - Portfolio

Personal portfolio of Shubham Pawar, SDE II at AjnaLens (B glasses by Lenskart).

Modern 3D design: React + TypeScript + Vite, react-three-fiber (Three.js) hero scene, framer-motion scroll animations, Tailwind CSS v4.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs dist/
```

Deployed on Netlify as a static site (dist/).
